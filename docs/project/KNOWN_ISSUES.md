# KNOWN_ISSUES

2026-10-13，0.3.0 预览版；沿用平台限制，增加组合内容与回滚边界。

| ID | 已知事项 | 影响 |
| --- | --- | --- |
| K02 | 未进行真实 iOS / iPadOS Safari / 主屏、VoiceOver、字体放大验收 | Chromium 的 iPhone Air / iPad mini 参数测试不能替代实机 |
| K03 | 锁屏 / 后台声音与常亮受平台限制 | 前台计时，切出暂停，不补算未知活动 |
| K05 | 本地数据受源变化、清理或存储回收影响 | 保留 JSON 备份；不同浏览器 / 线上不自动同步 |
| K06 | 备份只合并并保留本机冲突 | 没有覆盖、完整替换或删库重置 |
| K07 | 10000 条 / 10MB 容量上限未完整性能验收 | 已验证 1000 条；大容量需实测 |

| K11 | 0.1.x 不能打开已经升级的 v2 数据库 | 不能直接回滚旧二进制；采用 v2 兼容补丁，保留数据，见 ADR 0003 |

| K13 | 0.2.x 无法正确显示新的徒手 / 换位动作 | 组合数据回滚使用保留新字段与显示能力的 0.3.x 补丁，见 ADR 0004 |

v1→v2 实际升级与备份迁移已验证；不再列为未完成。旧学习和历史数据保留在备份，不再提供对应浏览入口。
