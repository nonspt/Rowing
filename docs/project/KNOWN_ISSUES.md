| ID | 已知事项 | 影响 |
| --- | --- | --- |

| K14 | 0.3.x 不理解计次草稿与记录 | 计次数据回滚使用保留 circuit-2 / stageProgress / 次数结果的 1.0.x 补丁，见 ADR 0006 |
| K13 | 0.2.x 无法正确显示新的徒手 / 换位动作 | 组合数据回滚使用保留新字段、动作显示与计次语义的 1.0.x 补丁，见 ADR 0004 |

本轮修复布局边界不齐、深色低区分度、清空后缺省 profile、临时模式错误 Promise 契约及主题跨窗口不同步；取消、冲突与删除失败回滚已纳入验收。

v1→v2 实际升级与备份迁移已验证；不再列为未完成。旧学习和历史数据保留在备份，不再提供对应浏览入口。
