## 产品事实

- 单页 #/plans，无底部导航或首次训练偏好表单。
- 模板：轻松有氧、基础耐力、长时有氧；无氧适应、短间歇强化、无氧进阶。每种支持 2 / 4 / 6 / 8 / 12 周。
- 自定义 1–52 周；有氧 / 无氧每周总训练次数均支持 1–5 次。无氧 1–2 次保持原间歇安排，3–5 次为 2 次间歇加恢复划行，强度课间隔至少 3 个日历日。调整热身、放松和主训练 / 间歇参数。
- 首页只保留跟练卡与日程卡；左卡恢复无标题的分组简要结构。总周期与每周完成次数合并到日程标题的周次选择，删除独立周期展开区；默认主页面适配 iPad 横屏高度。
- 当前计划、下一次跟练、周日程；可改日期、跳过、恢复、切换已保存计划和开启新一轮。
- 自动推进到下一周；跳过不计完成，提前结束保存本次但该日程仍待完成。
- 已有进度的自定义计划锁定类型、开始日期与频次，只修改待训练课程；已完成 / 跳过课程保持原快照。未改变频次或日期时保留用户调整的待训练日期。
- 无氧跟练需主动确认已有基础与当日无疲劳 / 不适；实际训练间隔 ≥48h、日历周最多两次，H02 需先完成无不适的 H01。无氧模板含低强度有氧恢复课。
- 新无氧模板默认组合：快划 / 充分划船恢复 → 离机 20 秒 → 深蹲 20 / 休息 40 → 俯卧撑 20 / 休息 40 → 上机 20 秒。适应 3 轮（27 分钟），强化 / 进阶 4 轮（约 32 分钟）。低强度有氧恢复课沿用。
- 自定义无氧可选择仅划船或徒手组合，选择深蹲 / 俯卧撑，每个动作可计时 10–30 秒或计次 1–30 次，休息 30–90 秒（对计时动作至少两倍时长）；新自定义默认 3 轮。
- 旧无氧 focused 计划可预览后加入组合，仅更新待训练课程并保留日期 / ID / 完成与跳过快照；草稿阻止改变。旧无 training 的四周计划通过更换模板开始组合。
- 设置：主题、声音、备份、安装与等待更新，以及删除所有数据。删除展示范围 / 数量，可先备份，需主动勾选和再次确认；取消不改数据。
- 跟练由 followEffort 将课程目标 0–10 按 ×1.6 四舍五入为 0–16：热身 / 恢复 / 放松 3–5，常见有氧 5–6 / 6–8，短工作 11–13。当前用力大字、下一段独立强调、动作提示为辅助文字，操作按钮仍 ≥64px。
- 新参数模板属于应用安排，没有宣称官方背书或第三方专业审核。旧已确认课程参数仍保留。
- ≥960px 且横向的窗口使用宽布局：计划 / 日程两栏、模板三列、选择计划与自定义弹层扩宽。自定义计划设置 / 划船训练 / 徒手动作分组，横屏等大模块同屏，各自滚动；跟练为独立全屏 main 页面，首页卸载；左完整时间线、中央更宽的计时与上下排列操作、右上下排列用力 / 下一段，按钮 ≥72px。较窄或竖向窗口沿用单列，跟练按钮 ≥64px。

- 双主题共享暖金色按钮 #f5c66b；浅色强调文字 #785214，深色 #f5c66b。深色背景 #11151b、卡片 #20262f、次级面板 #303a47。统一 Token，实际可见文字对比与输入边界验收。
- 跟练与日程卡等高，操作位于日程卡底部，周期信息在右上周次；今天按计划时区框选并在每分钟 / 回到页面刷新，训练状态加粗。跟练三列共用上下边界，当前阶段自动在时间线自身滚动区内定位，已完成 / 当前 / 待训练有文字和颜色区分。

## 架构与数据

- React / React DOM 19.2.6、TypeScript 5.9.3、Vite 8.0.16，原生 CSS / SVG / IndexedDB / SW，无新增依赖。
- UI → application → domain → Repository → Storage；计时仍使用 SessionController 单调前台时钟与 owner / lease / revision 保护。
- presets 定义模板；plan-definition 校验参数；focused-plans 生成完整周期与进度；plan-service 修改状态；旧四周生成器仅供旧计划兼容。
- IndexedDB home-rower-db v2，沿用七个 store，升级只更新元数据；旧记录、课程快照、学习进度、草稿均保留。
- 新 Plan 可选 training，旧计划缺该字段，按原四周日程继续；新 Scheduled 带 slot。备份导出 v2、导入 v1 / v2，版本一致性 / 数量 / 关联 / 参数严格校验，原子合并保留本机冲突。
- 感受可不填：assessed=false，rpe=0 不代表用户自评；未输入设备指标保持 null。完整课程绑定日程，保存幂等。
- 16 级是跟练显示量表，不是机器阻力档位或标准 RPE 量表。课程 / 草稿快照与感受数据继续保存原 0–10 值；无数据库或备份格式变化，旧草稿恢复时自动换算显示。
- LocalStorage 只保存主题。没有账号、遥测、云同步、自动运动评分或设备控制。
- 保留旧数据字段及兼容规则；用户可主动确认清空所有本机用户数据，复用 v2 事务并保留 schema / 递增 revision，见 ADR 0005。v1 应用不兼容已经升级的 v2 数据库，回滚需 v2 兼容补丁，见 ADR 0003。
- PlanTraining.circuit 与 Stage.exercise 为可选元数据，缺省保持旧划船语义。组合由 domain/circuit 生成，独立恢复 / 换位为 recovery，徒手为 work。v2 存储 / 备份完整保留并校验，无 store / 索引 / 缓存策略变化；旧记录 / 草稿不自动改写。
- iPad 首页采用一屏两卡、真实计划统计、简要结构、周历与合并周期的周次；完整时间线仅在跟练左列，中央计时与上下排列控制，右侧用力 / 下一段上下排列。沿用 SVG、双主题、大按钮和窄屏响应。
- 组合依据与非专业审核边界见 product/组合训练说明；字段兼容与回滚见 ADR 0004。没有新增依赖。

- 计次课程使用 repetitions、stageProgress、completedRepetitions 可选字段，实际前台时长独立于预计值；用户确认后进入休息，提前结束不推断次数。旧计时路径保留，计次数据需使用保留五秒调整阶段的 1.2.x 兼容补丁回滚。每次 3 秒仅用于估算日程 / 时间线，非动作节奏要求；见 ADR 0006。
- deleteAllData 校验预览 revision / 有效其他窗口租约，一次事务清空六个数据 store 对应快照与 lastBackupAt；异常全部回滚。外观重置为 system，跨窗口同步；不清理其他源数据 / 离线资源 / 安装。备份不含外观 key。
- 默认 profile 在 domain/profile 复用；清空后建立计划无需刷新。Repository 临时模式也采用 Promise 失败契约，数据失败保留。

## 1.1.0 当前增量事实

- 自定义采用可复用 RangeField，仅保留滑块与同行只读数值；动态恢复下限随快划 / 徒手计时变化联动。

- 新课程生成 / 启动包含调整；App 初始化、结束 / 丢弃草稿、无草稿导入时仅升级待训练课程。存在草稿时延后维护，完成 / 跳过与当前草稿不改写。无 schema / 缓存策略变化。
- 心率只保存静态参考区间，原始身体信息不进入 UI / 源码 / 存储 / 备份；模板卡和跟练显示估算，设置保留来源。短段不追赶，徒手 / 设备调整段不设心率目标。具体区间为应用在通用参考带内的分配，非官方处方，见 product/心率参考说明。
