## 确认与实现

用户已确认训练内容，当前内容版本 1.0.0。课程参数保持原设计；旧草案课程、计划和草稿快照保留，不需要删库或破坏性迁移。

首页采用单一页面标题，训练入口／周摘要／计划教学入口；课程改紧凑列表。筛选、阶段、常见错误、自检、设备读数、安装与数据细节按需展开；未保存、存储失败、临时模式、离线和高强度条件继续明确显示。核心流程全部回归。

动作图示按 Concept2 官方规则原创绘制，统一关节模型固定肢段长度、脚踏与水平手柄路径；分步演示先腿／躯干／手臂，再手臂／躯干／腿。SVG 几何检查不等同于教练评价。

图标、动作、周图表、训练进度使用 SVG。按钮、原生表单、开关外观、弹层与布局使用 HTML / CSS；安装 PNG 从 SVG 源文件生成。不能声称所有界面元素均为 SVG。
