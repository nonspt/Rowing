# iPad mini 7 横屏适配与参数验收

更新：2026-10-13；应用 1.0.0。

按 [Apple iPad mini（A17 Pro）技术规格](https://support.apple.com/zh-cn/121456)的 2266×1488 像素，以及 [Apple 布局规格](https://developer.apple.com/design/human-interface-guidelines/layout)的 744×1133 pt / @2x，使用横屏 **1133×744 CSS px / DPR 2 / 触控**模拟。截图直接核验为 2266×1488。

## 布局规则

- ≥960px 且横向的窗口启用宽布局；按可用窗口尺寸响应，不强制横屏，也不使用机型识别。
- 左侧计划统计、下一次跟练与课程结构，右侧周历 / 日程 / 计划操作；周期信息从日程卡底部展开查看。默认仅两卡，横屏常规字号一屏显示，完整时间线在左卡内部滚动。
- 类型与周期并排、模板三列；选择计划 / 自定义使用较宽弹层，自定义基础与训练参数两列。
- 跟练全屏：左侧状态 / 倒计时 / 已跟练 / 进度，右侧并列当前用力 / 下一段，操作按钮并排；下方当前与后续五个阶段。横屏计时字号约 181px，用力约 46px，主要按钮至少 72px；用力上限继续为 16，无图示。
- 较窄窗口与竖向窗口沿用单列，手机跟练主要按钮至少 64px；文字放大允许纵向滚动，禁止横向溢出。

## 验收条件

- 横屏 1133×744、工具栏压力 1133×650、竖屏 744×1133、分屏压力 567×744，各自浅色 / 深色。
- 安全区压力 top 24 / bottom 21；为注入 Token 的压力值，不是 Safari 实测数据。
- 1133×440 验证较短可用高度下的输入与保存，不宣称模拟了真实软键盘。
- 200% 字体采用 34px 对照默认 17px，检查模板、表单、跟练与结束页面。
- 检查 44px 触控区域、横屏全部关键训练信息及按钮无需滚动、顶部标题不遮挡课程名 / 阶段、原生模态焦点、实际开始 / 暂停 / 结束 / 保存、刷新与离线。
- Chromium 移动视口在 Windows 可报告约 1133.6 / 向上取整 1134px，DPR 有浮点尾差。测试容许 1 CSS px 取整误差、DPR 差值 <0.0001；仍严格核验目标视口与 PNG 2266×1488，不放宽触控、遮挡或溢出标准。

组合训练另外运行 `pnpm test:circuit`，检查完整训练、徒手暂停 / 刷新恢复、备份与旧计划。

运行 `pnpm test:ipad-mini`；`pnpm test:pages` 在 /Rowing/ 子路径同时执行手机与平板流程。通过 APP_URL 可指定线上地址，所有数据为隔离浏览器合成数据。

实际通过结果、构建与线上证据见 [VALIDATION_REPORT](VALIDATION_REPORT.md)。截图 / 机器报告保存在被 Git 忽略的 test-results/ipad-mini。

当前为 Chromium 参数模拟，真实 iPadOS Safari / 主屏、动态工具栏、VoiceOver 与锁屏行为仍需设备验证。
