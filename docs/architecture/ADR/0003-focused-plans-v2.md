# ADR 0003：聚焦训练计划与 v2 数据兼容

2026-10-10；已采纳，应用 0.2.0。

用户明确要求只保留训练计划和跟练，并加入多周期、自定义、有氧 / 无氧分类。本决策替代 ADR 0001 的四标签与手动记录产品范围；架构、本地优先与 PWA 原则继续有效。

## 决策

- 主界面单页，删除其他功能 UI；保留主题、声音、数据保护和 PWA 支撑。
- 新计划存完整周期，training 定义类型 / 周期 / 频次 / presetId 或 custom；每次课程保存快照与 slot。独立纯函数生成和校验，服务负责事务。
- 不复用旧四周规则标识伪装新计划。新参数单独版本 focused-1 / custom-1。
- IndexedDB 显式从 1 升为 2，原七个 store 不删除，升级仅更新元数据。旧字段和无 training 的计划读取兼容。
- v1 备份先验证结构版本与原范围，再转换 root 至 v2 后执行全部数据校验；v2 备份保留新定义。未来版本拒绝导入。
- 自动推进替代手动周进阶；未完成 / 提前结束的课程保留待训练，跳过不计完成。
- 不填感受使用 assessed=false，不把默认值作为用户报告。

## 迁移与回滚

升级不清空数据库、记录、课程、学习或草稿。IDB versionchange 关闭旧连接；被旧窗口阻塞时告知关闭后重试，原数据保留。

0.1.x 使用 indexedDB.open(name,1)，不能打开已升级的 v2 库，也不能识别新计划定义。因此不能直接部署 0.1.x 作为数据无损回滚。问题版本应发布支持 v2 的兼容补丁或在 0.2.x 上回退受影响 UI；保留 v2 Repository / 校验与计划字段。保持 main 新增提交，禁止强推或删库恢复。

重要数据可导出 v2 备份，再导入仍支持 v2 的已验证构建。若只持有 v1 旧备份，可在干净的新浏览器源恢复旧版，但这不包含 v2 新增数据，不能声称完整恢复。

## 验证与限制

21 项规则测试覆盖定义、周期、快照保存、编辑和备份。浏览器实际创建 v1 数据库，保留旧计划、手动记录、学习与草稿后用 v2 打开并刷新核验；1000 条旧备份导入 / v2 导出通过。

完整回滚演练与 10000 条容量尚未执行，记录于 KNOWN_ISSUES；不将删库作为方案。
