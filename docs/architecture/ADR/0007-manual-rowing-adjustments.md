# ADR 0007：手动划船设备调整与旧快照保护

日期：2026-10-13；状态：采纳；应用 1.1.0。

用户要求连续划船阶段用力改变前预留 5 秒；徒手不加时。沿用 Stage 可选元数据，adjustment=true、kind=recovery、exercise=row，严格为 5 秒且无计次字段；显示下一段用力与设备调整提示，不将 16 级显示当作阻力档位。

withRowingAdjustments 仅在原相邻划船且 rpe 不同处插入，排除已有调整 / 徒手 / 换位，重复应用返回原对象。总时长增加，工作时长不变，内容标记 +adjust-1。生成课程、开始跟练及待训练维护复用该函数。

无草稿时维护待训练课程，保留日期 / ID，递增课程版本；完成、跳过、当前草稿与旧记录保留原快照。存在草稿时延后；保存或丢弃后才维护待训练课程。Repository 事务保护并发，未变内容不重复维护 revision。

数据库与备份外层仍 v2。旧记录 / 草稿可恢复，新调整标记在 v2 备份中保留并严格校验。回滚应采用保留计次和调整语义的 1.1.x 兼容补丁，不删库或直接部署不理解新提示的旧 UI。
