# ADR 0004：以可选课程元数据实现划船 / 徒手组合

日期：2026-10-13。状态：接受；应用 0.3.0 预览。

用户要求无氧课加入俯卧撑、自重深蹲，并优化 iPad 信息密度。复用 Stage、SessionController、Repository、备份和原生 UI，保持前台计时、暂停 / 租约 / revision / 更新草稿保护。

## 决策

- Stage 增可选 exercise：row、squat、pushup、rest、off-rower、on-rower；沿用四种 kind。徒手为 work，换位和休息为 recovery，因此既有工作统计和保存流程可复用。
- PlanTraining 增可选 circuit（动作数组、工作秒数、休息秒数）；仅无氧可用。Domain 校验边界，circuit.ts 负责生成和标签，UI 只选择参数和显示。
- 新模板在采用时显式写入默认组合。缺 circuit 的旧模板继续生成原划船课；旧快照 / 草稿不自动迁移。
- 旧 focused 无氧计划通过显式应用与 revision 校验更新待训练课程。保留 ID、日期、完成 / 跳过快照与所有记录；有草稿时禁止改变。
- 编排版本 circuit-1；新组合仍沿用 H01 / H02 标识，保留现有进阶资格语义。已有纯划船 H01 完成也满足 H02 前置。
- 不新建数据库 store 或改变索引，数据库 / 备份仍为 v2。新可选字段完整导出并严格导入校验；缺字段备份正常读取。不同源仍通过预览 / 确认合并迁移。
- iPad 增课程结构、周历、周期格与只读阶段列表；不引入图示、设备控制或后台运动推断。

## 验证与回滚

规则测试覆盖生成、恢复 / 换位、边界、工作统计、旧计划显式升级、完成快照与 CAS；浏览器覆盖完整计时、徒手暂停 / 刷新恢复、实际备份导入、自定义、旧计划与离线，手机 / iPad 继续回归。具体执行证据见 VALIDATION_REPORT。

旧 0.2.x 可忽略新字段，但不会正确显示徒手动作与换位名称，不能作为组合数据的功能兼容回滚目标。修复采用保留 circuit-1 读取、动作显示与 v2 存储的 0.3.x 补丁；需要回退视觉时仅回退 CSS / UI 布局。通过新提交发布，不强推、删库或改写完成数据。实机 Safari、专业内容审核及完整回滚演练仍待验证。
