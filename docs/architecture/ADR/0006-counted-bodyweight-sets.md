# ADR 0006：徒手按次数跟练与完整时间线

日期：2026-10-13。状态：接受；目标发布版本 1.0.0。

## 决策

- Circuit 可选 targets，为深蹲 / 俯卧撑分别选择 time（10–30 秒）或 reps（1–30 次）。旧 workSeconds 作为缺省计时目标，旧计划、完成课程和草稿不自动重写。休息沿用 30–90 秒，对计时动作继续要求至少两倍时长。
- 模板与自定义均可调整徒手目标；Service / Repository 校验 revision 和有效租约，有草稿时拒绝修改。仅重建待训练快照，保留日期、ID、完成 / 跳过课程与记录。
- Stage 可选 repetitions；计次段 durationSeconds 按每次 3 秒估算，只用于日程总时长与时间线的位置，标注“约 / 预计”。这不是动作速度要求，不触发自动完成。编排版本 circuit-2；纯计时课程仍为 circuit-1。
- 包含计次动作的 Draft 增可选 stageProgress（阶段序号、本段实际毫秒、已完成阶段结果）。elapsedMs 保留实际前台用时，计次段等待用户点击“已完成 N 次 · 下一段”。计时段继续倒计时，换位 / 休息 / 热身 / 放松仍完整计时。
- 完成次数作为 StageResult.completedRepetitions 记录，仅在主动确认后写入。提前结束保留 partial 与实际用时，不推断未完成次数。实际总时长与工作时长由真实阶段结果计算，保存幂等。单次实际用时沿用 6 小时数据上限，达到上限暂停，要求结束保存。
- 原计时 Draft 不增加游标，原 advance 路径保留。新字段严格校验：目标范围 / 动作类型、进度序号、完成顺序、实际时间合计、次数与状态、完整记录与草稿关联。
- 数据库仍为 v2，七个 store、索引、CAS、租约、备份外层格式和 SW 策略不变；新增元数据通过现有快照完整导出、校验、预览和原子合并。旧 v1 / v2 数据继续读取，无删库或自动覆盖迁移。
- 首页只保留跟练 / 日程两卡；周次切换位于日程标题，周期进度从卡内展开。左卡训练结构按 course.stages 原顺序显示每一段，包括所有恢复 / 休息 / 换位；时间线可键盘、触控滚动。跟练界面沿用必要目标与大操作按钮。

## 兼容与回滚

0.3.x 不理解计次语义，不能作为已有计次数据的功能回滚版本。回退视觉时只回退 CSS / 布局，数据和会话处理采用保留 circuit-2、stageProgress、completedRepetitions 的 1.0.x 补丁。迁移前可导出 JSON，导入仍需预览 / 确认，不覆盖本机冲突；数据库版本无迁移。备份、断点恢复和旧数据的实际验证以 VALIDATION_REPORT 为准。

V1.0.0 正式编号由用户明确要求。模拟浏览器结果不代表真实 iPadOS Safari / VoiceOver / 主屏 / 低电量测试，未执行的范围保留在 KNOWN_ISSUES。
