# 心率参考说明

2026-10-13，应用 1.1.0。仅参考估算，非实测、医疗处方或经个体评估的安全界限。应用仅含最终区间，不保留或展示原始身体信息。

[AHA 心率指南](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/target-heart-rates)以群体年龄公式估算最大心率，中等强度参考 50–70%，较高强度参考 70–85%，并强调个体差异。基础信息不足以确定实际最大心率、阈值或受药物影响的区间。下表是应用在该通用参考带内的分配，不是来源给出的官方逐计划处方。

| 模板 | 参考 bpm | 使用方式 |
| --- | --- | --- |
| 轻松有氧 | 94–113 | 连续划行，从区间较低处开始 |
| 基础耐力 | 113–132 | 连续划行参考，结合体感 |
| 长时有氧 | 103–122 | 长时间稳定参考，不只按时长增加强度 |
| 无氧适应 | 132–150 | 划船工作段参考，不追赶数值 |
| 短间歇强化 | 141–160 | 划船工作段参考，不持续维持全程 |
| 无氧进阶 | 141–160 | 不仅因模板名进阶就提高参考上限 |

热身 / 放松和有氧恢复采用较低参考带；短段恢复心率可能继续升高，数字不决定恢复完成，更不跳过恢复。徒手和设备调整不设置心率达标目标。应用无设备读数、心率告警或自动强度控制。

[Concept2 心率说明](https://www.concept2.com/blog/a-perspective-on-heart-rate-training)强调个体差异与体感。[短间歇研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9813096/)观察到心率反应滞后；据此采用不追赶短段心率的设计，不能把研究对象直接当作当前用户。个体差异、健康状况和药物可能影响心率。
