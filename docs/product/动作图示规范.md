# 动作图示与 SVG 约定

> 0.2.0 更新：当前只保留跟练中的 SVG 动作示意，学习页与独立动画控制器已按用户新范围移除。本文后续有关学习演示的操作为历史记录；几何约束、官方依据、统一 Icon 和安装资源规则继续有效。

更新：2026-10-08；应用 0.1.1；动作模型 `rowing-motion-1`。

## 官方依据

- [Concept2 RowErg 动作教学](https://www.concept2.com/training/rowing-technique)：已读取入水、驱动、结束、回桨的官方动作要求。
- [Concept2 官方动作图解](https://www.concept2.it/files/pdf/us/indoor-rowers/Dynamic_UserManual.pdf#page=7)：第 7 页四阶段图解入口。该手册的设备结构为 Dynamic；本项目只引用动作阶段，绘制通用固定脚踏侧视机身。
- [British Rowing 室内划船技术](https://www.britishrowing.org/knowledge/rower-development/british-rowing-technique/indoor-rowing-technique/)：补充官方教学入口。

SVG 为依据动作规则绘制的原创简化图，不声称来自官方授权、官方背书或专业动作评估。没有复制官网图片、商标或视频；原始图解可通过学习页“教学依据”打开。没有做官方图像的像素比对。

## 绘制与运动约束

| 动作 | 本项目表达 |
| --- | --- |
| 入水位 | 手臂伸展，髋部前倾，小腿接近垂直，头颈自然 |
| 驱动 | 蹬腿后打开躯干，最后拉柄；手柄沿水平路径移动 |
| 结束位 | 双腿接近伸展、轻微后倾，手柄到躯干前方下肋附近 |
| 回桨 | 先伸手、再前倾；手柄超过膝部后屈膝前滑 |
| 身体连接 | 固定脚踏、座椅随髋部滑动；上下臂与上下腿肢段长度固定 |
| 动画循环 | 六步连续插值，回桨较从容；速度只是教学演示，不指定训练划频 |

代码中的长度和角度仅服务于图形构造，不作为人体测量或统一动作角度标准。

## 实现与交互

`src/domain/rowing-motion.ts` 维护关节模型和六步顺序；`RowingFigure.tsx` 是所有划船姿势的统一 SVG 渲染入口，首页、学习与跟练共同使用。

学习页和五个教学专题使用 `RowingDemonstration.tsx`：循环播放、暂停、慢速和六步点选；“分步查看”默认收起。尊重系统减少动态效果；页面隐藏或图示离开视区后停止动画。所有内容随 PWA 离线缓存，不依赖在线视频。跟练中的静态动作提示保留，以减少计时页面的额外操作。

## SVG 检查结论

应用导航、操作与状态图标通过统一 `Icon` 输出 24×24、圆头描边、currentColor 的 SVG；动作、周图表与训练进度也使用 SVG。展开指示采用相同路径的 SVG mask。没有 Emoji 图标、Icon Font、界面位图或 Canvas 替代。

按钮、表单、文字、弹层、开关轨道和布局使用语义 HTML 与 CSS；原生表单控件的系统符号由浏览器绘制。安装图标需要 PNG 兼容资源，由 `public/icon.svg` 经 `scripts/generate-icons.mjs` 生成；它们不用于应用内教学图示。

[源码审计结果](../../test-results/svg-audit.json)与[模拟验收](../project/IPHONE_AIR_ACCEPTANCE.md)记录实际证据。几何自动检查验证顺序、连接和长度，不等同于教练对所有姿态的专业评价。
