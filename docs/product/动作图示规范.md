# SVG 元素规范

2026-10-10；0.2.1。

## 当前界面

- 统一 Icon 组件：24×24、2px 圆头圆角描边、currentColor、aria-hidden；图标按钮提供 aria-label。
- 计划与跟练进度使用 SVG rect 和 progressbar 语义；折叠箭头为统一路径的 SVG mask。
- 学习、独立动作演示与跟练图示已按用户要求移除，跟练只显示必要文字 / 倒计时 / 进度与大按钮。
- 无 Emoji、Icon Font、Canvas 或应用内位图插图；语义表单、文字、弹层、开关和布局使用原生 HTML / CSS。原生选择器的系统符号由浏览器绘制。
- Manifest / apple-touch-icon 为 SVG 来源的四个 PNG 兼容文件，使用 scripts/generate-icons.mjs 派生，不用于应用内展示。
- 审计脚本 scripts/audit-svg.mjs 检查当前 UI；被忽略的 test-results/svg-audit.json 保存机器证据，不作为已提交文档依赖。

## 历史动作依据

旧版动作教学参照 [Concept2 动作要求](https://www.concept2.com/training/rowing-technique)、[官方四阶段图解](https://www.concept2.it/files/pdf/us/indoor-rowers/Dynamic_UserManual.pdf#page=7)和[British Rowing 技术](https://www.britishrowing.org/knowledge/rower-development/british-rowing-technique/indoor-rowing-technique/)绘制原创简化侧视图，不宣称官方授权或动作评分。

历史关节模型 src/domain/rowing-motion.ts 的固定肢段、水平手柄与先腿 / 躯干 / 手、回桨反序规则仍有几何测试；当前前端不再引用或展示该模型。旧角度与长度仅服务于示意，不构成人体测量标准。
