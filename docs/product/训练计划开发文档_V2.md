# 训练计划与跟练开发文档

版本：2.3.0；2026-10-13；应用 1.1.0 正式版。本文替代旧开发文档的产品范围，沿用原技术栈、iOS 风格与数据保护要求。

## 产品目标与流程

用户只需要为家用划船机选择计划并跟练。主要流程：选模板 / 自定义 → 查看周日程 → 跟练。当前只保留这一条主链路。

首页为空时显示模板库；已有计划时显示当前计划与下一次跟练、周日程、更换 / 编辑按钮。设置提供主题、声音、数据备份、安装 / 更新及主动确认删除所有数据。删除教学、自检、独立课程浏览、历史 / 趋势、手动补录入口。旧数据继续留存，可导出。

P0：有氧 / 无氧模板、多周期、自定义、完整日程、跟练计时、暂停恢复、进度保存、离线及旧数据兼容。没有新增 P1 / P2 扩展需求。

## 模板

所有模板支持 2、4、6、8、12 周。每周以开始日期为锚点，并非固定周一；日历周无氧上限按用户时区计算。

| 模板 | 目的与结构 | 每周 | 单次 |
| --- | --- | --- | --- |
| 轻松有氧 | 连续稳定划行，主段由 8 分钟逐周增加至 15 分钟；热身 4、放松 3 | 3 次 | 15–22 分钟 |
| 基础耐力 | 主段由 15 分钟增加至 20 分钟；热身 / 放松各 5 | 3 次 | 25–30 分钟 |
| 长时有氧 | 主段由 20 分钟增加至 30 分钟；热身 / 放松各 5 | 3 次 | 30–40 分钟 |
| 无氧适应 | 20 秒快划 / 100 秒恢复，配深蹲、俯卧撑与独立换位 / 休息，3 轮 | 2 次（1 次组合、1 次轻松有氧） | 15–27 分钟 |
| 短间歇强化 | 两次 4 轮划船 / 深蹲 / 俯卧撑组合，中间轻松有氧 | 3 次（2 次组合） | 15–32 分钟 |
| 无氧进阶 | 4 轮组合；第二周起一节快划 30 秒 / 恢复 90 秒，其余快划 20 / 恢复 100 | 3 次（2 次组合） | 15–32 分钟 |

有氧每第 4 周降低主段量，且不短于初始量。旧无氧纯划船模板每第 4 周降为 4 组，新组合适应始终 3 轮、强化 / 进阶始终 4 轮。无氧热身 8、放松 5 分钟，最后一次恢复保留。稳态段 RPE 3–5、短工作段 7–8、热身与恢复 2–3。不由未知心率、功率或距离推断负荷。

有氧 / 无氧表示训练侧重点，短间歇也有有氧参与与恢复课，不能理解为能量系统互斥。结构参考 [Concept2 训练指南](https://www.concept2.com/training/guide)、[强度与心率说明](https://www.concept2.com/blog/a-perspective-on-heart-rate-training)及[渐进建立规律](https://www.concept2.com/training/plans/couch-to-consistency)。这是本应用编排，不是复制或宣称官方训练计划；原课程 1.0.0 用户已确认，新编排标识 focused-1。

新组合的徒手段、恢复 / 换位与动作来源见 [组合训练说明](组合训练说明.md)。新模板默认组合；旧计划不会自动改写，可显式加入组合并保留已有训练数据。

## 自定义

- 名称 1–60 字、开始日期、类型、1–52 周。
- 有氧每周 1–4 次；主段 5–60 整分钟；热身 / 放松各 3–15 分钟。
- 无氧每周 1–2 次；每组 10–30 秒、恢复 60–180 秒且至少为工作段三倍、3–10 组；热身 8–15、放松 5–15 分钟。
- 无氧可选仅划船或组合；组合支持深蹲 / 俯卧撑，动作 10–30 秒、动作后休息 30–90 秒且 ≥动作两倍。离机 / 上机各 20 秒，准备不足可暂停；新自定义默认 3 轮。
- 当前实现自定义单次结构并重复于各周。没有每周单独编排或任意阶段拖拽编辑器，以控制复杂度。
- 采用前验证，事务保存全周期快照；编辑后续课程不改已完成 / 跳过课程。已有进度时冻结类型、开始日期和频次；可另存并使用建立新一轮。
- 未改变开始日 / 频次时保留调整过的待训练日期；已保存计划可暂停、恢复。没有删除计划或重置数据入口。

## 跟练、进度与异常

- 单次课程按热身、主段 / 恢复、放松计时；组合额外计时徒手动作、换位与休息，并显示当前动作与轮次。只计前台已确认活动，切出与锁屏暂停；恢复最近检查点。
- 按用户要求，跟练用力显示上限为 16；从原 0–10 目标按 `round(原值 × 16 / 10)` 换算上下限。热身 / 恢复 / 放松 2–3 → 3–5，有氧 3–4 → 5–6、4–5 → 6–8，短工作 7–8 → 11–13。随着阶段切换自动变化，模板、自定义和旧草稿统一适用。
- 用力数值大字、下一段类型 / 时长独立强调；动作提示缩小为辅助文字。16 级为应用显示量表，不表示设备阻力或标准 RPE；底层课程与感受仍保存原 0–10 语义，无数据迁移。
- 关闭跟练自动保存暂停草稿，首页可继续；丢弃需明确确认。
- 完整训练自动结束，点“完成并返回计划”幂等保存记录与日程进度；感受可选，未填记录 assessed=false。
- 提前结束保存实际时长，该日程保留待训练状态，可再次跟练；少于 1 秒不生成训练记录。
- 当前周没有待训练课程后自动推进，最后一周处理完后显示本轮结束；跳过不计入完成数。
- 改日期限当前计划周、不能与其他有效课程重叠，无氧课程之间至少三个日历日。实际启动另校验 48 小时间隔与日历周最多两次。
- 无氧开始需主动确认基础与当日状态；30 秒进阶需先完成无不适的 20 秒课程。
- 跨窗口运行租约不可抢占，陈旧 revision / 预览拒绝覆盖。存储失败保留草稿，显示重试与导出；不可用时明确进入临时模式。
- 完成保护不能替代设备与身体评估，出现不适时停止。

## 架构与交付

UI / Application / Domain / Repository / Storage 分层沿用；原组件、单调时钟、反馈与 PWA Adapter 继续复用，无新增依赖。

IndexedDB 升级为 2，Plan 增可选 training，Scheduled 增 slot；兼容旧无 training 的四周计划与原记录字段。备份 v1 → v2 转换校验后原子合并。迁移、回滚与 v1 兼容边界见 ADR 0003。0.3.0 增可选 PlanTraining.circuit / Stage.exercise，v2 库和备份保持，缺省为原划船行为；组合 contentVersion=circuit-1。旧 0.2.x 不适合作为组合数据的功能兼容回滚目标，见 ADR 0004。

保留 SVG 图标与进度；独立教学页、演示控制器与跟练图示均按用户要求删除。跟练只保留课程、阶段、计时 / 次数目标、用力程度、下一段与大操作按钮；计次段需主动确认完成。原生 HTML 表单 / dialog 与 CSS 负责布局。安装 PNG 从 SVG 派生。保持双主题、安全区、44px 目标、键盘焦点与 reduced motion。

横屏适配：以 iPad mini 7 的 1133×744 / DPR 2 为目标，并覆盖工具栏后 650 高度和安全区。首页仅跟练卡与日程卡：左卡完整逐段竖向时间线，长列表在卡内滚动；右卡紧凑周历 / 日程、标题内周次切换与卡内展开的周期进度，常规字号首屏完整显示操作。模板三列、自定义参数两列。跟练全屏，左侧当前动作 / 计时或次数，右侧用力 / 下一段并列与 ≥72px 按钮，底部当前及后续阶段。竖屏、分屏或手机回到原有单列；200% 字体允许纵向滚动访问，不强制方向。安全区使用既有 env Tokens，原生表单与弹层逻辑沿用。

验收：六模板 × 五周期、52 周边界、组合顺序 / 换位 / 休息 / 计时、旧计划升级、保存 / 编辑 / 切换、完整跟练与异常、v1 数据升级与备份、PWA 离线更新、iPhone Air 及 iPad mini 参数模拟。真实执行记录见 VALIDATION_REPORT，实际 iOS / iPadOS 待设备验收。

## V1.0.0 界面与数据管理（历史，当前界面以文末 V1.1 为准）

双主题共享暖金色按钮；白底强调字采用金棕色，暗色强调字采用亮金色。背景、卡片、次级面板与控件边界分别定义 Token。iPad 计划 / 日程与跟练等高对齐，操作均使用明确文案和 ≥44px 点击区域；更换计划为日程卡内紧凑按钮。今天按计划时区框选，训练状态加粗，其他周不错误标注今天。

设置删除流程：查看完整范围与数量 → 可导出备份 → 主动勾选 → 确认删除。删除用户快照与备份时间、恢复声音 / 外观默认，不改变数据库 / 缓存格式；CAS 和草稿租约保护、异常原子回滚。清空后可直接创建计划，原 JSON 备份可恢复训练数据，外观始终按单独设置处理。见 ADR 0005。

## V1.0.0 完整时间线与徒手目标（历史）

首页仅跟练卡和日程卡。左卡训练结构按实际 stages 顺序显示全部项目、开始时间和时长 / 次数，包括所有热身、恢复、休息、离机、上机和放松；组合重复阶段逐条保留。横屏时间线在卡内滚动，主页面一屏展示。周次切换并入日程标题，周期进度从卡内展开，今天框选、训练加粗、紧凑操作继续保留。

模板和自定义可在徒手动作中逐个选择按时间（10–30 秒）或按次数（1–30 次），深蹲 / 俯卧撑可混合。计次段显示目标和大确认按钮，主动完成后才切换休息；暂停 / 刷新 / 备份保留实际进度，提前结束不推断次数。日程按每次 3 秒估算，只用于约 / 预计显示，不要求动作速度，不自动完成计次段。保存实际前台时长与明确完成次数。参数与兼容详见 ADR 0006，数据库 / 备份外层仍为 v2。

## V1.1.0 当前覆盖

本段覆盖旧版页面结构描述：首页周次包含周期与每周完成次数，左卡无标题的简要结构；全屏跟练卸载首页，左完整时间线 / 更宽中央计时操作 / 右用力与下一段上下排列，区域内自动定位。自定义滑块与数值对齐联动，模板采用前可选徒手计时或计次，预设详情只显示日期与分别列出的课程结构。休息名称为站立休息；连续划船用力改变前增加五秒设备调整，徒手 / 换位不增加，见 ADR 0007。心率参考与信息最小化见 [说明](心率参考说明.md)。
